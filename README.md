# Chen Yibo — Academic Homepage

Personal academic homepage for **Chen Yibo**, an undergraduate researcher in the Department of Automation at Tsinghua University.

The site is intentionally minimal and research-oriented. It highlights current research interests, academic background, contact information, GitHub, and CV.

- `styles.css` — responsive academic-style layout
- `script.js` — lightweight navigation/reveal behavior
- `assets/chenyibo_cv.pdf` — curriculum vitae

This repository is published as a static GitHub Pages site.
